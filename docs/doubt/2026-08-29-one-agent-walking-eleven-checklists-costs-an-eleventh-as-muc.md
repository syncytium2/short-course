# "One agent walking eleven checklists costs an eleventh as much"

**Status:** OPEN
**Parked:** 2026-08-29 by `Mac/9b26b5c4`

## What I actually have
`what-it-costs.html` states that eleven agents cost roughly eleven times one agent, and that one
agent walking the same eleven checklists costs an eleventh as much. Murderboard finding B10
(`reviewer-2`) says neither half is measured, and the second half is probably wrong in the stated
direction — one agent doing eleven passes in a single conversation accumulates context across all
eleven, so its input grows superlinearly rather than staying flat.

## Why I do not trust it
There is **no single-agent row** in the table, no single-agent run in the log, and no arithmetic
anywhere. It sits fifteen lines above the page's own best line — *"a number an agent gives you
about its own consumption is a claim, not a receipt."*

## What would settle it
Run it once: one agent, the same eleven checklists, same document, measured. That is a cheap
experiment and it would make the strongest argument on the page an empirical one.

## What breaks if it is wrong
The page's central justification for paying 11x — *independence is the product* — is currently
supported by an unmeasured ratio. The **argument** is sound regardless (independent readers cannot
be talked round by each other); it is the **number** that is unsupported. If the true ratio is 3x
rather than 11x, the recommendation does not change but the honesty of the page does.
