From nothing to a working web page

The Short Path

Four steps. You will not follow a list of install instructions, because Claude gives you those itself, one at a time, and can look at a screenshot of what is actually on your screen.

  1. Pay for Claude Code

    A few minutes · $20 a month

    Go to claude.com/pricing and choose Pro: $20 a month, or $17 a month if you pay for a year up front. Sign up with an account you mean to keep. Everything you build will hang off it.

    The free plan will not work. It includes the chat window and not Claude Code, and the last step needs Claude Code. If your employer already provides Claude Code, ask them how to sign in and skip this step.

  2. Open the Claude app

    One minute

    Either the desktop app from claude.ai/download or claude.ai in your browser. Sign in with the account you just paid for. This is the chat window, and for the next step it is your guide.

  3. Ask it to get you set up

    Twenty minutes or so · mostly waiting for downloads

    Paste this into the Claude app. It installs two things: VS Code, the program you will work in, and the Claude Code extension that lives inside it.

    Paste into the Claude app 
    I'm on a Mac and I have never installed developer tools. I've just paid for Claude Pro.

Walk me through installing Visual Studio Code and the Claude Code extension for it, one step at a time. After each step, stop and wait for me to tell you what I see before giving me the next one. I may paste a screenshot instead of describing it.

We're done when VS Code is open on a new, empty folder called my-site, Claude Code is open inside VS Code, and I'm signed in to it.

    When anything looks different from what it said, take a screenshot and paste it in. That is what the app is for here, and it is faster than describing it.

    If VS Code asks whether you trust the authors of the files in this folder, choose yes. It is your own empty folder, and choosing no quietly switches Claude Code off.

  4. Tell Claude Code what you want

    As long as it takes · in VS Code, not the Claude app

    In the Claude Code panel inside VS Code, say what the website is for. Say it the way you would to a colleague: who uses it, and what it does for them. Fill in the highlighted part.

    Paste into Claude Code, in VS Code 
    I want a website that lets me paste in a column of plasma osmolality readings and shows which ones fall outside 275–295 mOsm/kg, with a plot of all of them.

Build it in this folder as web pages that open in my browser, with no accounts and no server. Work only in this folder. Before you install or download anything, tell me what and why, and wait for me.

When it works, tell me how to open it.

    Claude Code asks before it creates or changes a file. Read what it wants to do, then allow it. This folder is where it is meant to work.

    The first version will not be exactly right. Say what is wrong, in plain words, and let it try again. That back-and-forth is the work, not a sign it is failing.

How you know it works

A page that looks right has not yet shown you it works. Give it an input you already know the answer to. If it flags readings, include one you know is out of range. If it adds things up, check one total by hand.

If the answer is wrong, tell Claude Code exactly which input gave which wrong answer.

If you get stuck

Go back to the Claude app, paste a screenshot, and say what you were trying to do. If it is stuck too, Cold Start is the long version of this path, with every step written out.
