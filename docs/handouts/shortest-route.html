The Shortest Route

A website a learner can edit from the Claude app — whether it needs a repository, and whether an agent maintaining documentation can spare them from learning git. Two questions, answered from material this course already holds.

Assembled 2026-08-30 by extraction, not by walking it. Every claim below comes from cold-start.html, search-to-shipped.html, four-barriers.html, points.md or the vendors' own current documentation, cited in place. Nothing here was invented for this page.

Nobody has walked this route. Neither has Cold Start — it carries the same warning. The order and the timings are unconfirmed, and a step that is wrong has no way of announcing itself here. Never murderboarded.

The two questions, as asked. Is a repo necessary? — and can the agent maintain sufficient docs to avoid having to teach a noob git?

Short answers: yes, and no — but the second no is smaller than it looks. The repo is forced by the product, not by good practice. And the learner does not need git; they need four facts about state, none of which is a command. That distinction is the whole page.

1 · Three routes, and what each one actually is

the field

“Edit it in the Claude app” describes three different products with three different requirements. They are not variants of one thing.

RouteRepo?Terminal?What you getWhat it is not
A · Artifact none none A page published from a conversation, private by default, at a claude.ai address. Not a file the learner owns, not their domain, and its history lives inside somebody else's system.
B · Claude Code on the web required none A real project the learner edits by asking, from a browser or the mobile app. Not repo-optional. See below.
C · Folder → Cloudflare none required A custom domain served straight from a folder on the laptop. Not editable from the Claude app, and the terminal is the thing being avoided.

Route A is not a straw man — this course runs on it. All four handouts, this one included, are published as artifacts and read that way. It is a real channel. What it cannot do is be the learner's, at their own address, with a copy they keep.

2 · Is a repo necessary? Yes — and the line is not where it looks

question one

A repository is not needed to put a site on the internet. Cold Start already settles that, and recommends against the repository road:

Cloudflare publishes straight from a folder on your computer. There is no repository involved at all, so your repo stays private and it still costs nothing. Cold Start 7.3 — “This is the road most people should take, and it is three steps shorter.”

The repository is needed to edit from the Claude app. That is a hard requirement of the product, stated twice in its own documentation:

Cloud sessions need access to your GitHub repositories to clone code and push branches. Claude Code on the web — GitHub authentication options
Platform restrictions: repository cloning and pull request creation require GitHub. Claude Code on the web — Limitations

There is an escape hatch and it does not help this learner. A local repository with no GitHub remote can be bundled and uploaded to a cloud session — but that is done by typing claude --cloud in a terminal, and the documentation adds that “sessions created from a bundle can't push back to a remote.” It requires the terminal to avoid the terminal, and the work cannot come home. It is not a route.

So the honest statement of the cost

Not “you need version control.” It is: one free account, created in a browser in four minutes, because otherwise the editing surface will not open. Cold Start already asks for that account, on entirely separate grounds, as the first step of the first phase — and already calls it the step people skip:

It reads as a step for people who publish software, and you are not publishing software. But it is what gives your project a second place to exist. … This is the step people skip because it seems premature, and it is the one whose absence is documented twice in this course's own material. Cold Start 1.1 — “Create a GitHub account — this one is not optional”

The decision therefore costs nothing new. It removes an option Cold Start was already telling people not to take.

⚠ One thing this reverses, and it is a finding against Cold Start

7.3's recommendation assumes a terminal. Take the terminal away and its ranking inverts. Cloudflare-from-a-folder is shorter only when wrangler and a shell are already on the table. For a learner who never opens one, the folder road is not three steps shorter — it is unreachable, and the repository road is the only one left.

This is filed as a finding, not fixed. cold-start.html is not edited by this page; another session holds it. Someone has to decide whether 7.3 gains a second audience or whether this route is a separate sheet.

3 · Can documentation replace teaching git? No — and this course already says why

question two

The proposal is that the agent keeps the docs good enough that the learner never has to understand what is underneath. That is a fix, and this course has a table for grading fixes:

TierWhat it isWhat it costs to ignore
ProseA rule written in an instructions fileNothing. It is skipped silently.
ChecklistA step someone must rememberNothing, when they are busy.
TestSomething that fails loudlyA red line. Cheap and visible.
StructureThe wrong thing is not reachableIt cannot be ignored.

“Agent-maintained docs” is tier one. It is the most available fix and the weakest, which is exactly the pairing the course's own worst incident is about:

Writing a sentence costs nothing, takes five seconds, feels like having solved something, and produces an artifact you can point at. Every stronger fix costs more and looks like less. The weakest mechanism is the most available one, and availability beats effectiveness unless something forces the issue. docs/cases/2026-08-28-the-weakest-fix-is-the-most-available.md

And documentation has a second defect the table does not show: it rots without saying so. Search to Shipped names it as one of six things that will bite you —

Staleness. Documentation was true when written and says nothing about the difference. Including official pages, including yours, including what you told the agent to remember last month. Search to Shipped, Phase 6

A doc that Claude maintains is not exempt from this. It is more exposed to it, because nobody re-reads a file that is always being updated by something else.

The exception, which is the part worth keeping

The material carves out one kind of document that does hold, and states precisely why:

A project instructions file is an instruction to behave — it competes with everything the model already believes, and it loses. A glossary is not an instruction. It is the fact the session reasons from. A rule asks the model to override a prior; a definition replaces the prior. That is why one holds and the other does not. It Looked Right, challenge 4

That is the answer, split in two. Docs written as rules for the learner (“always commit before you deploy”) are tier one and will be skipped. Docs written as definitions — this word means this state — are the exception, and they are exactly what a beginner is missing. Claude can maintain the glossary. It cannot maintain the discipline.

4 · What the learner actually has to know, which is not git

the finding

On this route the learner types no git commands at all. Claude commits, Claude pushes. So the teaching burden is not a command set — it is four states, and the gap between each pair of them. Every one is a fact, not a habit, which puts them in the exception carved out above.

StateMeansThe gap under it
Written The file on the disk changed. Nothing has been recorded. Closing the session can lose it.
Committed The change is in the record, with a reason attached. Committing is not pushing. An unpushed commit exists on exactly one machine and reaches nobody, including you tomorrow on a different one.
Pushed It is on GitHub. A second machine, and Claude, can see it. Pushed is not published. The visitor still gets yesterday's page.
Deployed The address serves the new bytes. This is the only one a reader can observe, and it is the last to happen.

Two of those four gaps are already documented failures in this estate, which is why they are the ones on the list. Committed-not-pushed is Search to Shipped step 12, written after “a night's work that reached the next morning as nothing at all.” Pushed-not-deployed happened during the writing of this page: the session board records a rebuilt page sitting correct in the repository while “the live page's description says 30 until someone runs npx wrangler deploy.” Four states, two of them already proven to catch people who do know git.

What this costs against the course's stated git scope

The outline fixes the git scope at three commands — commit, diff, log — and says explicitly: no branches, no remotes, no merge. points.md already records that this does not survive contact with step 0:

D1 pre-empts §6. If a GitHub account is step 0, a remote exists from the first hour, and §6's “commit, diff, log — no remotes” is already contradicted at the door. points.md §D

This route does not open that tension. It closes it in the cheap direction. The scope stops being a list of commands the learner runs and becomes a list of states they can check — and diff survives unchanged, because reading a diff for scope is one of the four checks that need no code. The learner reads; the agent types.

5 · The route

one evening

Five steps. Nothing installed, nothing typed into a terminal, and every step ends with a condition you can check — because an action and its report are two different events.

  1. 1

    Create a GitHub account.

    Free, four minutes. Two-factor on during signup, not afterwards. Pick a username you are willing to be known by later. If your work touches research data or human subjects, ask first whether your institution requires its own host — that is a governance question, not a preference. Cold Start 1.1, unchanged.

    Done when you are signed in, 2FA is on, and the username is one you will keep.

  2. 2

    Get a Claude plan that includes Claude Code on the web, and find out which kind it is.

    The web product is in research preview for Pro, Max and Team accounts — a free account will not open the door. Read What It Costs before committing to anything: a personal plan is an allowance you hit and stop; an institutional billing code is usually uncapped, and nothing stops or warns.

    Done when you can sign in at claude.ai/code, and you can say what happens when you use too much — it stops, or it bills.

  3. 3

    Make an empty repository on github.com, in the browser.

    New repository → tick Add a README → Create. That tick is what makes it a repository with something in it, which is what a cloud session needs to clone. Keep it private. Then at claude.ai/code, connect the GitHub account and pick the repo. No git init, no terminal.

    Done when the repository is visible on github.com in a browser, and it appears in the picker at claude.ai/code.

  4. 4

    Say the whole thing in one sentence, then ask for one element of it.

    “A web page that shows my recordings one at a time and lets me mark the bad ones.” If you cannot say it in a sentence, you are not ready to ask for it. Then break it into parts, and do one element, never two. Review the diff for scope — what did it touch that you did not ask about? — and let Claude commit and push.

    Done when the change is visible on github.com, and you can name in one line the single change that just happened.

  5. 5

    Connect the repository to Cloudflare Pages, once.

    In the Cloudflare dashboard, connect the GitHub repository. Private repositories are supported and the whole setup is in the browser. From then on every push redeploys, which is what removes the fourth state from the learner's hands — pushed and deployed stop being two events. The custom domain, if you want one, is Cold Start Phase 7 and can wait.

    The alternative is GitHub Pages, also browser-only — but on the free plan it serves from public repositories only, and private is the right default for research. That trade is Cold Start 7.3's, restated.

    Done when the URL loads on your phone, off your wifi — and then again after the next change, without you doing anything.

Step 5 is doing more work than it looks. Auto-deploy on push is the only structural element on this page — tier four, the wrong thing is not reachable. Every other protection here is prose. It is what lets the learner hold three states instead of four, and it is bought once, in a browser, in about ten minutes.

6 · The decision record

phase 4 format

Written in the form this course teaches, because this is exactly the case that form is for: a choice between two real options, both defensible, made on a date.

decisions/0001-a-repository-is-required-for-the-claude-app-route.md
Date: 2026-08-30  ·  Status: proposed

What we chose

A GitHub repository, created in a browser, as the substrate for the shortest route to a learner-editable website. Claude Code on the web is the editing surface; Cloudflare Pages on push is the publishing mechanism.

What we rejected

Artifacts alone — no repository, no account, genuinely shortest. Rejected because the learner ends with no file they own, no address of their own, and a history living inside a system they cannot export. The course's whole second half is an argument that the record is the point.

Cloudflare-from-a-folder (Cold Start 7.3) — no repository, and shorter if there is a terminal. Rejected because there is not one, and because the result is not editable from the Claude app, which was the requirement.

Why

Not for version control, and not on best-practice grounds. The product requires it: cloud sessions clone and push through GitHub, and the no-GitHub fallback needs a terminal and cannot push back. Given that, the repository is free and Cold Start was already asking for the account on independent grounds.

What it costs

One free account. No git commands are taught — four states are, and two of the four have already caught people in this estate who do know git.

Revisit if

Claude Code on the web gains a browser-only path that does not require GitHub; or artifacts gain an export the learner keeps and a custom domain; or the learner's institution mandates a non-GitHub host, in which case cloud sessions become bundle-only and this route does not survive.
