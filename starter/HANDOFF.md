# Handoff — where this stopped, and what is next

**Three lines at the end of every session**, and a fourth for what you are not sure of.
What happened, what is unfinished, what is next, what you are guessing. Cold Start step 5.5.

The next session has no memory of this one. That is true whether the next session is an
agent tomorrow morning or you on Thursday, and it is the reason a session that ran all
evening and left no handoff delivered nothing — the work exists and nobody can find the
thread back into it.

**Ask for it rather than writing it:** *"Write the handoff for the next session: what
happened, what is unfinished, what is next, and what you are guessing. Four lines."* Then
read it, because a handoff that describes a success that did not happen is worse than an
empty file.

## Why there is a fourth line

The next session reads this and not the work behind it, so every sentence here arrives with
the same confidence whether it was measured or assumed. **The uncertainty is what gets lost
first** — not because anyone lies, but because a hedge is the part of a sentence that does
not tell the reader what to do, and it is the first thing a summary drops. A guess written
here as *"the export is correct"* is read tomorrow as a finding, and nothing in the sentence
says which one it was.

So the doubt gets its own line, where it cannot be smoothed away by the sentence around it.

**Write what would settle it, not how you feel about it.** *Probably fine* and *worth
checking* evaporate on the first re-reading. *"I never opened the output file — open it"* is
an instruction a stranger can carry out, and that is the only kind of doubt that survives.

**Newest at the top**, so the file opens on the thing that matters. Old entries stay; this
is a record, not a status board. When it gets long enough to be annoying, that is the point
at which it has become valuable — move the old entries to the bottom under a `## Earlier`
heading rather than deleting them.
