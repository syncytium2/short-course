# Handoff — where this stopped, and what is next

**Three lines at the end of every session.** What happened, what is unfinished, what is
next. Cold Start step 5.5.

The next session has no memory of this one. That is true whether the next session is an
agent tomorrow morning or you on Thursday, and it is the reason a session that ran all
evening and left no handoff delivered nothing — the work exists and nobody can find the
thread back into it.

**Ask for it rather than writing it:** *"Write the handoff for the next session: what
happened, what is unfinished, what is next. Three lines."* Then read it, because a handoff
that describes a success that did not happen is worse than an empty file.

**Newest at the top**, so the file opens on the thing that matters. Old entries stay; this
is a record, not a status board. When it gets long enough to be annoying, that is the point
at which it has become valuable — move the old entries to the bottom under a `## Earlier`
heading rather than deleting them.
